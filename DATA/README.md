## Data Set Establishment Details

### Summary

The dataset contains **29 uncleaned columns** and approximately 2.27 million rows.

The dataset was pulled from [NYC Open Data](https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95). 

We downloaded the CSV spreadsheet directly from the website and have not included the raw file here in the data folder due to its size.
